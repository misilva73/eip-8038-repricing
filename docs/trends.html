Across all runs

One chart per estimated parameter — run on the x-axis, the selected metric on the y-axis, one line per client. Toggle clients above or via each chart's legend; hover a point to see the fit that produced it.

Mixed anchors across runs. These runs were not all fit at the same anchor rate (75, 100 Mgas/s), and proposed gas scales linearly with it — so part of the movement in the gas charts is a methodology change, not client performance. Spans that cross an anchor change are drawn dashed, and each point's anchor is in its tooltip. The runtime (ms) metric is anchor-independent and comparable throughout.
