Goal targets

Target gas values we want clients to reach for the key 8038 parameters, checked against each client's latest estimate. A client clears a goal when its estimate is at or below the target — lower is faster.

  • The account goals (COLD_ACCOUNT_ACCESS, ACCOUNT_WRITE) require a client to clear both the CODE and NOCODE variants — both values are shown in the cell.
  • The write goals subtract the bundled cold-access component before comparing, and what they subtract is the matching access goal's own target — retarget an access goal and the write rows move with it: STORAGE_WRITE uses COLD_STORAGE_WRITE − 2100 (the COLD_STORAGE_ACCESS goal) and ACCOUNT_WRITE uses COLD_ACCOUNT_*_WRITE − 3000 (the COLD_ACCOUNT_ACCESS goal), each floored at 0.
  • The targets are fixed — they don't move with the anchor rate. The estimates they're checked against do, though: this run is anchored at 100 Mgas/s, so a cell reads "can this client reach this cost at a 100 Mgas/s throughput goal?"
